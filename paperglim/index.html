원문과 AI를 한 공간에 두었어요.

번역은 원문 바로 옆에.

페이지마다 필요한 만큼 한글번역을 열어보세요. 번역 문장에 마우스를 올리면 원문의 같은 부분이 함께 표시돼요. 핵심 영어 용어는 그대로 남겨두고요.

한 페이지만, 또는 논문 전체를 번역할 수 있어요. 완료된 번역은 앱을 다시 열어도 남아 있어요.

궁금한 문장에 바로 질문.

문장을 드래그해서 설명을 요청하거나 직접 물어보세요. 후속 질문도 이어갈 수 있고, 저장된 설명은 그 문장 위에서 다시 열거나 목록에서 찾아갈 수 있어요.

질문은 논문 전체를 바탕으로.

대화와 선택 영역의 설명이 같은 논문 맥락을 공유해요. 별도의 요약 버튼으로 3문장 요약부터 문제, 방법, 결과와 한계까지 살펴보세요.

Zotero 데스크톱 앱과 로컬 API 연결이 필요해요. 클라우드에만 있는 PDF는 먼저 Mac에 내려받아 주세요.

Apple의 안전한 앱 실행 안내

미리 알아두면 좋은 것들.

추가 결제나 API 키가 필요한가요?

PaperGlim은 무료이며 자체 AI 요금을 청구하지 않아요. AI 기능은 사용자가 설치하고 인증한 Codex 또는 Claude Code CLI로 실행돼요. 사용 권한과 한도, 비용은 연결한 서비스의 계정 설정을 따라요. Codex Fast는 지원 계정에서만 선택할 수 있고 한도를 더 소모해요. Claude Fast는 앱에서 제공하지 않아요.

내 PDF와 대화는 어디에 저장되나요?

논문 목록과 읽던 위치, 저장한 선택 영역 설명과 완료된 번역은 Mac에 보관돼요. 번역은 페이지별로 삭제할 수 있어요. PaperGlim의 별도 서버는 없어요. AI를 요청하면 필요한 논문 텍스트와 해당 대화가 연결한 AI 서비스로 전송돼요. 오른쪽 패널의 대화는 앱 안에서 임시로 유지되며 새 대화나 앱 종료로 지울 수 있어요. CLI는 매 요청 기록을 남기지 않는 모드로 실행하지만, AI 서비스 자체의 데이터 처리는 해당 서비스의 정책을 따라요.

어떤 Mac과 PDF를 지원하나요?

macOS 13 이상의 Apple Silicon Mac 전용이에요. Intel Mac은 지원하지 않아요. 텍스트를 선택할 수 있는 PDF를 지원해요. 스캔 PDF의 OCR, Zotero 그룹 라이브러리와 주석 동기화는 아직 지원하지 않아요. 복잡한 수식·표·다단 문서는 번역 범위나 문장 연결이 어긋날 수 있고, AI의 답변과 번역은 원문과 함께 확인해야 해요.

Chrome에서 PDF를 열면 자동으로 연결되나요?

현재는 내려받은 PDF 파일을 앱에서 여는 방식이에요. Finder에서 PDF의 기본 연결 앱으로 PaperGlim을 지정할 수 있어요. 브라우저 내 PDF 화면을 자동으로 대체하는 확장 기능은 아직 없어요.
