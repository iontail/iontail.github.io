원문 옆 한글번역.

한 페이지부터 논문 전체까지, 번역을 원문 바로 옆에서 읽어요. 번역 문장에 마우스를 올리면 대응하는 원문도 함께 표시돼요.

핵심 영어 용어는 그대로. 완료된 번역은 다음에 열 때도 남아 있어요.

논문 전체에 질문하고 요약하기.

논문 전체 내용을 바탕으로 질문해 보세요. 요약 버튼을 누르면 3문장 요약과 함께 문제, 방법, 결과와 한계를 정리해 줘요.

선택한 문장을 더 깊이 이해하기.

문장을 드래그해 설명을 요청하고 후속 질문을 이어가세요. 저장한 설명은 해당 문장에 마우스를 올려 다시 확인할 수 있어요.

Zotero 로컬 API 안내

미리 알아두면 좋은 것들.

추가 결제나 API 키가 필요한가요?

PaperGlim은 무료이며 별도 API 키를 요구하지 않아요. AI 기능에는 설치하고 로그인한 Codex 또는 Claude Code가 필요해요. 사용 권한, 한도와 비용은 연결한 계정의 요금제와 설정을 따라요.

PDF와 대화는 어디에 저장되나요?

라이브러리, 읽던 위치, 저장한 문장 설명과 번역은 Mac에 보관해요. 오른쪽 패널의 대화는 임시로 유지돼요. PaperGlim의 별도 서버는 없지만, AI 요청 시 논문 텍스트와 질문은 연결한 AI 서비스로 전송되며 해당 서비스의 데이터 정책을 따라요.

어떤 Mac과 PDF에서 쓸 수 있나요?

macOS 13 이상의 Apple Silicon Mac에서 텍스트를 선택할 수 있는 PDF를 지원해요. Intel Mac, 스캔 PDF의 OCR, Zotero 그룹 라이브러리와 주석 동기화는 아직 지원하지 않아요. 복잡한 수식·표는 번역 연결이 어긋날 수 있어요. AI 답변과 번역은 원문과 함께 확인해 주세요.
