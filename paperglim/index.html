원문 옆 한글번역.

한 페이지부터 논문 전체까지, 번역을 원문 바로 옆에서 읽어요. 번역 문장에 마우스를 올리면 대응하는 원문도 함께 표시돼요.

핵심 영어 용어는 그대로. 완료된 번역은 다음에 열 때도 남아 있어요.

논문 전체에 질문하고 요약하기.

논문 전체 내용을 바탕으로 질문해 보세요. 요약 버튼을 누르면 3문장 요약과 함께 문제, 방법, 결과와 한계를 정리해 줘요.

선택한 문장을 더 깊이 이해하기.

문장을 드래그해 설명을 요청하고 후속 질문을 이어가세요. ‘수식·개념 풀이’는 기호와 풀이 과정, 작은 예시를 정리해 줘요. 저장한 설명은 원문에 마우스를 올려 다시 확인하세요.

문장 너머,
그림과 표까지.

페이지의 영역 선택 아이콘을 누르고 축·범례·캡션을 함께 선택하세요. 선택 이미지와 논문 본문을 바탕으로 비교 조건, 읽히는 결과와 해석의 한계를 정리해 줘요.

다시 볼 부분에는 ‘다시 보기’를 남기세요. AI 호출 없이 표시만 저장하고, 저장된 설명 목록에서 원문으로 돌아갈 수 있어요.

내 AI, 내 라이브러리.

쓰고 있는 AI를 연결해요.

Mac에서 로그인한 Codex 또는 Claude Code를 사용해요. 별도 API 키 없이, 앱에서 모델을 골라 시작하세요.

PaperGlim은 무료예요. AI 사용은 연결한 계정의 요금제와 한도를 따라요.

Zotero의 정리도 그대로.

Zotero에 보관한 PDF를 컬렉션과 하위 컬렉션별로 불러와요. 논문을 다시 정리할 필요 없이 읽기와 AI 기능을 사용할 수 있어요.

이렇게 사용하세요.

읽는 흐름에 필요한 기능만 익혀보세요.
앱 상단 도움말에서 사용 가이드를 다시 열 수 있어요.

처음 시작하기
  1. PDF를 창에 드래그하거나 ⌘O로 여세요. 앱에 포함된 ResNet 예제로도 시작할 수 있어요.
  2. 번역·질문을 사용하려면 AI 연결을 마치고, 입력창 아래에서 모델을 선택하세요.
  3. 상단 도움말 아이콘이나 macOS의 도움말 → 사용 가이드를 열면 기능별 안내와 설정 바로가기를 볼 수 있어요.
나란히 번역하고 논문에 질문하기
  1. 페이지 우측 상단의 한글번역을 누르세요. 1페이지의 모두 번역으로 전체 논문을 번역할 수도 있어요.
  2. 번역 문장 위에 마우스를 올려 대응하는 원문을 확인하세요. 두 칸 사이 경계를 드래그해 폭을 조절할 수 있어요.
  3. 문서 우측 상단에서 AI 패널을 열어 질문하거나 논문 요약을 누르세요. 답변의 근거 보기에서 페이지를 누르면 원문으로 이동해요.
수식·그림을 이해하고 다시 볼 부분 남기기
  1. 텍스트를 선택하고 설명이나 수식·개념 풀이를 누르세요. 같은 창에서 후속 질문을 이어갈 수 있어요.
  2. 그림·표는 페이지 왼쪽 위의 영역 선택 아이콘으로 선택한 뒤 해설을 요청하세요. 방향키로 이동, Shift+방향키로 크기 조절, Enter로 선택할 수도 있어요.
  3. 선택 영역에서 다시 보기를 눌러 표시만 저장하세요. 문서 상단의 저장된 설명을 열어 필터링하거나 해당 원문으로 이동할 수 있어요.

AI는 읽히지 않는 숫자나 깨진 수식을 정확하게 복원하지 못할 수 있어요. 답변은 원문과 함께 확인해 주세요.

확대·검색·저장한 자료 관리하기

⌘+·⌘− 또는 ⌘+휠로 PDF를 확대·축소하고, ⌘0으로 기본 배율로 돌아가세요. ⌘F로 본문을 찾고 ⌘[로 이전 읽기 위치에 돌아갈 수 있어요.

앱의 글자·아이콘 크기는 설정의 화면·읽기에서 바꿀 수 있어요. 데이터·앱 정보에는 백업·복원이 있어요. 원본 PDF 파일과 임시 채팅은 백업에 포함되지 않으니 PDF는 별도로 보관해 주세요.

설치와 연결.

앱에 PDF를 드래그하면 읽기를 시작해요.
AI와 Zotero는 필요할 때 연결하세요.

앱 설치와 첫 실행

DMG를 열고 PaperGlim을 Applications 폴더로 옮겨주세요. 앱에 PDF를 드래그하면 읽을 수 있어요.

현재 베타는 Apple 개발자 인증서 서명·공증을 받지 않았어요. macOS에서 실행을 막으면 파일 출처를 확인한 후, 시스템 설정의 개인정보 보호 및 보안 → 그래도 열기에서 허용할 수 있어요.

Codex · Claude Code 연결

Codex 또는 Claude Code CLI를 설치하고 터미널에서 로그인해 주세요. 앱의 연결 설정에서 설치 여부를 확인한 뒤 모델을 고르면 돼요.

Zotero 연결

Zotero 설정의 고급 메뉴에서 “이 컴퓨터의 다른 애플리케이션이 Zotero와 통신할 수 있도록 허용”을 켜주세요. Zotero를 실행한 채 PaperGlim에서 동기화를 누르면 돼요. 클라우드에만 있는 PDF는 먼저 Mac에 내려받아 주세요.

Zotero 로컬 API 안내

미리 알아두면 좋은 것들.

추가 결제나 API 키가 필요한가요?

PaperGlim은 무료이며 별도 API 키를 요구하지 않아요. AI 기능에는 설치하고 로그인한 Codex 또는 Claude Code가 필요해요. 사용 권한, 한도와 비용은 연결한 계정의 요금제와 설정을 따라요.

PDF와 대화는 어디에 저장되나요?

라이브러리, 읽던 위치, 저장한 문장 설명·다시 보기 표시와 번역은 Mac에 보관해요. 오른쪽 패널의 대화는 임시로 유지돼요. PaperGlim의 별도 서버는 없지만, AI 요청 시 논문 텍스트·질문과 선택한 그림·표 이미지는 연결한 AI 서비스로 전송되며 해당 서비스의 데이터 정책을 따라요.

어떤 Mac과 PDF에서 쓸 수 있나요?

macOS 13 이상의 Apple Silicon Mac에서 텍스트를 선택할 수 있는 PDF를 지원해요. Intel Mac, 스캔 PDF의 OCR, Zotero 그룹 라이브러리와 주석 동기화는 아직 지원하지 않아요. 복잡한 수식·표는 번역 연결이 어긋날 수 있어요. AI 답변과 번역은 원문과 함께 확인해 주세요.
